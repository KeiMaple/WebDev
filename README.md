- **Browser Architecture:** Web Storage API integrations (`localStorage`/`sessionStorage`), basic Geolocation, and browser Notification permissions.
- **Standards & Accessibility:** SEO optimizations, modern document validation standards, and cross-platform responsive layout design.
- **Styling (in progress):** CSS selectors, the box model, colors & typography, and basic responsive layout techniques.

## 🚀 How to Run These Projects
 
1. **Clone the repository:**
```
git clone https://github.com/KeiMaple/WebDev
```
 
2. Navigate into any folder (e.g., `cd 01-flower-shop`).
3. Open the `.html` file directly in your preferred browser or run it with an extension like **Live Server** in VS Code.
